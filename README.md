# Customizable Tissue Box
OpenSCAD customizable tissue box for 3D printing. Building on code originally written by user `dukyduke` and posted on [Thingiverse](https://www.thingiverse.com/thing:4241105) under the [CC-BY-SA license](https://creativecommons.org/licenses/by-sa/3.0/). 

## Changes
- Add a separate retaining bar to keep the inner tissue box inside when the outer box is lifted
- Change pattern parameters to be more intuitive in relation to what you see in the output
- Translate comments to English
- Organize the customizable parameters into sections, and add more descriptions to them
